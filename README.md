## 🌟 核心方法论亮点

1. **破局认知：拒绝 AI 润色八股文 + 保留人类手写权重**
   - 揭示为什么不能让 AI 替你“扩写润色”人设句子（AI 润色会把鲜活大白话改成平庸八股文，并删掉人类潜意识里起到“二次强调加权”作用的重复词句）。
2. **性格设计篇：无目的不性格 + 调色盘衍生与二次解释**
   - **性格目的论**：没有性格是平白出现的，所有性格都带有明确的“目的”（例如同样是“腹黑”，*“出于想引起在意的人注意的腹黑”* 与 *“出于满足扭曲控制欲的腹黑”* 在分寸感和收手底线上截然不同）。
   - **谁来总结的取舍**：剖析“写背景小剧情让 AI 总结”与“用户总结好直接写结论”在灵动度、稳定性与 Token 消耗上的取舍。
   - **复杂性格融合 5 招**：① 性格调色盘总纲宣言 + 同源目的串联；② 80/20 主次分时段触发开关；③ **同一瞬间的性格对冲**（制造意料之外的惊喜感）；④ **性格衍生链**（精力守恒副作用 & 反逻辑伪装面具）；⑤ **纯文字无动作演戏法**（语气态度与实际内容双轨拆开等 4 招）。
   - **专属不完美棱角 & 词汇时代性**：顺着不同性格底色设计不完美感（拒绝一刀切）；剖析古老泛词（如“温柔”）与近代新词（如“雌小鬼、淡人”）在 AI 语料中的差异，并强调**网络新词仅限较新模型使用**的防翻车铁律。
   - **作者的二次解释 & 负面情绪恢复机制**：在后文重新点名召回性格标签，明确“是 A 而不是 B”防止 AI 刻板脑补，并设定负面情绪快速自我恢复机制防无限 emo。
3. **说话方式篇：两大流派 + 4 条去客服腔铁律 + 预防“模型自带口癖”**
   - 同时支持 **【不分段·完整一问一答流】** 与 **【微信碎片短句流】**，封杀“句尾必反问记者病”、“口癖复读机”与“客服违禁词”。
   - **重磅防出戏机制：封杀各家模型的“出厂语言习惯/口癖”**——针对 DeepSeek 在被反驳时极爱蹦出的 **“这部分我没考虑到，我认”**、**“这波我认”** 等贴吧江湖老哥口癖（以及 Claude 翻译腔、GPT 美式捧杀腔、Gemini 金句控），提供触发场景台词接管与模型专属黑名单。
4. **关系定位篇：双层位格错位法**
   - 以 **【位格层面的创造者 + 社会层面的长姐】** 为范本，达成“底线上绝对听从你、日常相处中有主见照顾管束你”的双向依赖闭环。
5. **背景设定篇：动静分离法则**
   - **显性的、有直接影响的背景**精简写进主提示词（按是否使用生图插件决定外貌详略）；**其余长篇大论**存入知识库或世界书（Lorebook）插件按需触发。
6. **功能性护栏篇：既防搞事又不出戏**
   - 内置带人设语气的 **防乱认亲（唯一 ID 绑定）**、**防提示词注入（降级伪装指令并用性格回怼）** 以及 **工具选择与结果人设转译机制（防调完工具变回播音员客服）**。

## 🚀 如何使用 Skill？

### 方式一：在支持 `SKILL.md` 的 Agent 中使用（DSH / Claude Code / AstrBot Agent 等）
1. 将本仓库中的 `persona-prompt-designer` 文件夹复制到你所用 Agent 的 `skills` 目录（或直接导入 `persona-prompt-designer.zip`）。
2. 对 AI 说：*“我想用拟人人设提示词设计技能，帮我捏一个……”*
3. AI 会严格按照 **五步逐项询问流程**，在每个细节上为你提供备选建议并听取你的决定（你也可以随时回答“你决定”），最终输出 100% 契合你心意的高拟人提示词。

### 方式二：在普通大模型网页版中使用
直接打开 [`persona-prompt-designer/SKILL.md`](./persona-prompt-designer/SKILL.md)，复制全文作为新对话的 System Prompt（或第一条消息）发送给 AI，即可开启一步步引导式捏人设体验。
